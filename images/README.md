## Cómo subirlas (la forma más fácil)

1. Entra a `https://github.com/antonio27cibrian-ship-it/Claudia/tree/claude/ebook-landing-page-oI4CR/images`
2. Botón **"Add file" → "Upload files"**
3. Arrastra las 4 imágenes, **renómbralas exactamente** como en la tabla de arriba.
4. Commit directo a la rama `claude/ebook-landing-page-oI4CR`.
5. GitHub Pages se redepliega solo en 30 seg.

## Recomendaciones

- Formato `.jpg` (no `.png`) — pesan menos, cargan más rápido.
- Reducir cada imagen a máximo **1600 px de ancho** antes de subir.
- Si una imagen tiene otro nombre real, dime y actualizo las referencias en el HTML.
